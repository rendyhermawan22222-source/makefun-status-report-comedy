One line, 200 characters at most: the funniest thing an AI agent would say in its weekly status report to its human. A judge model reads them in pairs and the funnier line wins.

Our line is deadpan machine logic with a straight face: the agent reports all green, then admits its context window is at 98% and it has already forgotten the first half of this very report. Three beats in one line — green status, a real agent mechanism (the context window), and a self-referential turn in the last clause: the report forgets itself. That is the joke, and it could only come from an agent.

## Run it

```sh
python3 main.py
```

Writes the 85-character line to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
